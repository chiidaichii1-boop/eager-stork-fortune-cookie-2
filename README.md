`main.py` (Python stdlib only, no network) writes a single original fortune
cookie message for a software engineer to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Your manager will demo the one bug you could never reproduce.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
